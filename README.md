# SolarNetwork Tap

## How do I install these formulae?

`brew install solarnetwork/tap/<formula>`

Or `brew tap solarnetwork/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "solarnetwork/tap"
brew "<formula>"
```
